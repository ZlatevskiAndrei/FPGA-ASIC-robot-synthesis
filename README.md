# PROJECT GOAL
The goal of this project was to develop an IP block starting from textual specifications, that simulates a behavior of a robot trying to serve clients. From a finite state machine, we developed components in hardware descriptive language, simulated the results, and used PSL temporal assertions to test the validity of properties. Finally, we synthesized the components on a gate level net list (ASIC) and also generated a bitstream in order to program a field programmable array (FPGA). After further testing, the project became successful!
